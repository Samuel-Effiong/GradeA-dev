(0b, merge 79ab843c; the SM's seven requirements and the conflict
resolutions in docs/evidence/merge-down-b12b/RESOLUTIONS.md).

Run from the vf2-s1 scratch worktree detached at COMMIT (the merge tip),
inside the rule 16/13/12 wrappers (the caller's script), output to a file,
stdin from /dev/null (rule 18). Usage:
  COMMIT=<sha> MUTANT_LOGS=<dir> python vf_md_b12b_mutants.py check |
  baseline | (no args: every mutant) | <mutant name>...

Every mutant is one resolved place of the merge taken out, judged by the
EXISTING modules that should guard it. No probe of v2's is needed for
these: each module is the merge's own guard, and a mutant that no module
catches is a finding for the merge (a resolution nothing holds).

Written 2026-10-08 BEFORE any run of this row, from reading the merge
blobs and the test lists of the judged modules. Honest limit: the judged
modules are large; for each mutant the tests that MUST be among the
failing ones are named where reading the test showed it ("must"); where
reading could not name them the expectation is only "some test of the
judged modules fails" ("weak"). KILLED = rc != 0, a "Ran" line, and every
"must" test among the failing ones. KILLED_WEAK = the same without a named
set. The full failing set of each run is printed beside the expectation, so
a reader sees what else fell. Rule 17: PYTHONDONTWRITEBYTECODE=1, __pycache__
of the mutated module's directory cleared before each mutant and after each
restore; restore is verified by sha256 against the commit's own blob.
Database tests: --keepdb (database test_vf2_s1).
"""

ENV = {**os.environ, "EXEMPT_EMAIL_DOMAINS": "", "PYTHONDONTWRITEBYTECODE": "1"}


def sha(b):
    return hashlib.sha256(b).hexdigest()


def clear_pycache(path):
    shutil.rmtree(pathlib.Path(path).parent / "__pycache__", ignore_errors=True)


def run(labels, log_name):
    LOGS.mkdir(parents=True, exist_ok=True)
    log = LOGS / log_name
    with open(log, "wb") as fh:
        out = subprocess.run(
            [sys.executable, "manage.py", "test", *labels,
             "--settings=settings_worktree", "--noinput", "--keepdb", "-v1"],
            stdout=fh, stderr=subprocess.STDOUT, env=ENV, stdin=subprocess.DEVNULL,
        )
    o = log.read_text(errors="replace")
    failing = sorted(set(re.findall(r"^(?:FAIL|ERROR): (\w+)", o, re.M)))
    ran = next((l for l in o.splitlines() if l.startswith("Ran ")), "Ran ?")
    summary = next((l for l in o.splitlines() if l.startswith(("OK", "FAILED"))), f"? rc={out.returncode}")
    return out.returncode, ran, summary, failing, o


if sys.argv[1:] == ["check"]:

        src = open(path).read()
        counts = [src.count(old) for old, _ in edits]
        for old, new in edits:
            src = src.replace(old, new, 1)
        ast.parse(src)
        print(name, path, counts, "parses")
    sys.exit()

if sys.argv[1:] == ["baseline"]:
    for p in (AI, SS, SX, SV):
        clear_pycache(p)
    rc, ran, summary, failing, o = run(BASELINE, "baseline.txt")
    print("baseline |", ran, "|", summary, "|", failing, flush=True)
    if rc != 0:
        print(o[-8000:])
    sys.exit(rc)

for name in sys.argv[1:] or MUTANTS:
    path, edits = MUTANTS[name]
    src = open(path).read()
    counts = [src.count(old) for old, _ in edits]
    if counts != [1] * len(edits):
        print(name, "APPLY_FAILED", path, counts, flush=True)
        continue
    for old, new in edits:
        src = src.replace(old, new, 1)
    ast.parse(src)
    labels, must = EXPECTED[name]
    try:
        clear_pycache(path)
        open(path, "w").write(src)
        rc, ran, summary, failing, _ = run(labels, f"{name}.txt")
        if rc == 0:
            status = "SURVIVED"
        elif ran == "Ran ?" or not failing:
            status = "BROKEN"
        elif not must:
            status = "KILLED_WEAK"
        elif all(t in failing for t in must):
            status = "KILLED"
        else:
            status = "KILLED_OTHER"
        print(name, "|", status, "|", ran, "|", summary,
              "| must", must or "(weak: any failure)", "| failing", failing, flush=True)
    finally:
        subprocess.run(["git", "checkout", "--", path], check=True)
        clear_pycache(path)
        ok = sha(open(path, "rb").read()) == sha(
            subprocess.run(["git", "show", f"{COMMIT}:{path}"], capture_output=True).stdout
        )
        print("  restore", path, "ok" if ok else "MISMATCH", "| __pycache__ cleared", flush=True)
