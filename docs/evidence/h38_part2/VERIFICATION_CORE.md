A SCHOOL-session course is reachable only while `user.school_id` equals the session's school. Null-school sessions fail closed. The object twin mirrors the Q version, and HelperAgreementTests checks them against each other.

- **Call sites** (part 1: 3, part 2: ~20): every one is a 1:1 swap of `teacher=user` / `course__teacher=user` / `teacher_id != user.id` for the helper or its twin. No site drops another constraint, so **H-22 / H-18 tenancy is not widened**.
